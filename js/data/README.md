# Site data

- `content.config.json` – fixture toggle and file paths
- `production/` – real catalogue (circuits and activities seeded; destinations/packages empty until import)
- `fixtures/` – development catalogue samples for layout preview only
- `home-fixtures.json` – homepage section samples (`development-fixtures`)
- `schemas/expected-import.example.json` – intermediate import format

See `/docs/content-architecture.md` for models, query rules, and import workflow.
